# Definitions

Git is basically built in version history for your computer.


# Useful commands

git commit

git push

git add --> 
Adds a file to be tracked and adds it to the stage.

git status

Shows which are staged, which are uncommitted but tracked, and which are untracked.

git restore --> basically the opposite of git add.
When you run it, it adds it back into the unstaged category.

git log --> shows the log of git commits and pushes.

origin/main and origin/HEAD refer to the main branch and the default branch of the chess repository.
In this class, they will stay together.

# Shortcuts

git commit -m "Message" --> Allows you to add a message explaining what the git commit is.

-u stands for "update" --> you can do git add -u to automatically stage every edit into the staged. Then you could restore some out.
